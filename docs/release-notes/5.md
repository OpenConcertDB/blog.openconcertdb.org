# Build 5: "You Can See Everything"
This build introduces a handful of complete overhauls and new things to try and break.
The major focus of this build was supporting user-submitted concert and tour posters, and several UI fixes and revamps.
Please remember, this is production data. If you need to make a concert to test with, feel free to do so.

A LOT of work was done in the backend to clean up the data. Setlist FM's data was pretty bad and caused a lot of issues. It'll be an ongoing process
to fix it all, but it's going.

This sprint was long-running and I don't recall who to attribute each feature to, so general thanks to **Shannon**, **Daniel**, and **Cassandra**.

## General
- **NEW:** Press-and-hold artist names in the Discover page, concert lineups, and tour lineups to  open the Apple Music artist preview sheet

## Discover
- **NEW:** Discover can now be customized. Scroll to the bottom of the page and tap “Customize” to change which rows are visible and what order they appear in.
- Enhancement: New venue card design
- **NEW:** “Active Tours” section

## Journal
- Complete redesign of the journal view.

## Venue
- Bugfix: When setting an address, the country code is also updated.

## Concerts
- **NEW:** You can now upload and view concert posters
- Enhancement: iCloud Shared photos are now also surfaced in the photos section, shown with a cloud icon in the lower-right corner.
- Enhancement: Can create calendar events from the Concert “3-dots” menu. 
- Added details menu in the Concert “3-dots” menu, so developers can confirm or retreive IDs easily

## Artist
- Indicate when an artist is on tour or has a tour coming up.

## Tour
- Bugfix: When adding/updating a concert and going back to the tour it will update immediately.
- **NEW**: You can now upload and view tour posters
- Complete redesign of the tour view

## Misc
- Started piping for iCloud sync in the next build

---

### What's next
The next build aims to focus on targeting older devices, getting the iPad views finished, and supporting closed and relocated venues.
